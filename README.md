# JITAI 기반 능동형 개인화 정서지원 AI 시스템
본 프로젝트에서는 JITAI(Just-in-Time Adaptive Intervention)를 적용하여 사용자의 최근 정서 상태, 과거 대화 기록, 알림 반응 및 이용 패턴을 분석하고, 필요한 시점에 적절한 방식으로  먼저 접근하는 능동형 정서지원 AI를 개발하고자 한다. 또한 대화 내용을 바탕으로 주요 사건과 감정을 분석해 일기를 자동 생성하고, 장기간의 정서 변화와 반복되는 고민을 시각화하여 자기 이해와 회고를 지원한다. 

## 유사 서비스 분석 및 본 프로젝트 개발 목표 
국내에서도 AI를 활용한 다양한 챗봇을 통해 정서지원 서비스가 제공되고 있으나, 후술할 Mello를 
제외한 대부분의 상용 서비스 중에서 사용자의 장기적인 정서 상태와 이전 알림 반응을 학습하여 
연락 시점과 내용을 사용자별로 지속적으로 최적화한다는 기술적 근거는 확인하기 어려웠다. 

본 프로젝트에서는 사용자의 과거 정서 상태와 상호작용 이력을 이용해 개입 내용과 함께 개입을 
시작할 시점과 최초 접근 방식까지 개인화하는 것을 목표로 한다. 또한 사전 정의된 알고리즘을 
통해 개입 내용을 제공했던 이전 사례와 달리 적응형 모델을 통해 장기적인 상호작용 흐름으로 
연결하는 것이 본 프로젝트의 차별점이다.
